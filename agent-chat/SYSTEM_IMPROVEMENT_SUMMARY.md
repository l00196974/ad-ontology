# 华为广告数据分析系统改进总结

## 🎯 改进目标

解决LLM在数据查询时的以下问题：
1. 频繁猜测错误的维度代码导致查询失败
2. 缺乏会话记忆，重复查询相同数据
3. 图表生成功能不稳定

## 🔧 实施的改进

### 1. 系统提示词优化

**添加了常用指标和维度列表**：
- 8个常用指标（click、pbiConvertRate等）
- 6个常用维度（promotionTarget、mediaName等）
- 明确的工具调用参数要求（format: "json"）

**强化了图表生成规则**：
- 明确禁止使用Python/HTML等其他格式
- 强制要求生成ECharts JSON配置
- 提供了详细的配置模板

### 2. 会话记忆功能实现

**在OpenAI客户端中添加了会话记忆逻辑**：
- 检查最近3条消息中的工具执行结果
- 提取数据查询结果并构建上下文
- 在系统提示词中注入最近的查询数据

**关键代码逻辑**：
```typescript
// 检查最近的消息中是否有数据查询结果
const dataMatch = msg.content.match(/工具执行结果：({.*?"data":\[.*?\].*?})/);
if (dataMatch) {
  const dataResult = JSON.parse(dataMatch[1]);
  if (dataResult.data && dataResult.data.length > 0) {
    recentDataContext = `用户在本次会话中已经查询过以下数据...`;
  }
}
```

### 3. 错误预防规则

**明确的禁止行为**：
- 不要猜测维度代码
- 不要使用错误的指标名称（如"clicks"应为"click"）
- 调用list工具时必须使用{"format": "json"}参数

**必须的行为**：
- 优先使用常用列表中的代码
- 查询前确认维度值的准确名称
- 图表请求时立即生成ECharts配置
