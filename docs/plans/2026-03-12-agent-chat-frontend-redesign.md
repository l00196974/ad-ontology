# Agent-Chat 前端重新设计方案

## 项目概述

重新设计华为广告数据分析Agent的前端界面，采用数据可视化主题，提升视觉美观度和用户体验。

## 设计目标

- 提升界面视觉美观度，从朴素设计转向专业数据分析工具风格
- 突出数据展示功能，优化图表和分析结果的呈现
- 保持功能完整性，确保现有的聊天、诊断、工具调用功能正常工作
- 提升用户体验，让界面更符合数据分析师的使用习惯

## 设计方案：数据可视化主题

### 整体布局架构

```
┌─────────────────────────────────────────────────────────┐
│                    顶部导航栏                              │
├──────────┬─────────────────────────────┬─────────────────┤
│          │                             │                 │
│   左侧   │         主聊天区域            │    右侧面板     │
│  会话面板 │                             │   (数据概览)    │
│          │                             │                 │
│          │                             │                 │
└──────────┴─────────────────────────────┴─────────────────┘
```

### 视觉设计系统

#### 配色方案
- **主背景**: 纯白色 (#FFFFFF) + 浅灰网格纹理
- **主色调**: 华为蓝 (#1890FF)
- **数据色彩**: 
  - 蓝色系: #1890FF, #40A9FF, #69C0FF
  - 绿色系: #52C41A, #73D13D, #95DE64
  - 橙色系: #FA8C16, #FFA940, #FFC069
  - 紫色系: #722ED1, #9254DE, #B37FEB
- **文字颜色**: 
  - 主文字: #262626
  - 次要文字: #8C8C8C
  - 辅助文字: #BFBFBF

#### 组件设计规范
- **卡片样式**: 白色背景 + 1px边框 (#F0F0F0) + 4px圆角 + 轻微阴影
- **按钮设计**: 扁平化设计，主要按钮使用华为蓝
- **输入框**: 简洁边框设计，聚焦时蓝色边框
- **图标**: 使用线性图标，统一2px线宽

### 核心组件重设计

#### 1. 顶部导航栏
- 左侧: 华为广告数据分析Agent Logo
- 中间: 当前会话标题
- 右侧: 设置按钮 + 用户头像

#### 2. 左侧会话面板 (280px宽度)
- **新建对话按钮**: 更突出的设计，使用主色调
- **会话列表**: 卡片式设计，显示会话标题和最后消息时间
- **快速诊断入口**: 折叠式菜单，展示6个诊断场景

#### 3. 主聊天区域
- **空状态页面**: 
  - 居中的欢迎信息
  - 6个诊断场景以数据仪表板风格展示
  - 每个场景卡片包含图标、标题、描述和关键指标预览
- **消息展示**:
  - 用户消息: 右对齐，蓝色背景，圆角气泡
  - AI消息: 左对齐，白色卡片背景，包含完整的数据展示区域
- **工具调用展示**: 
  - 以数据卡片形式展示，包含工具图标、状态指示器
  - 可展开查看详细参数和结果
  - 特殊处理诊断结果，以结构化方式展示SOP步骤

#### 4. 图表集成
- **图表容器**: 独立的白色卡片，带有标题和工具栏
- **图表样式**: 使用统一的数据色彩方案
- **交互功能**: 支持缩放、导出、全屏查看

#### 5. 输入区域
- **快速诊断按钮**: 水平排列，使用场景对应的颜色
- **输入框**: 多行文本框，支持Markdown预览
- **发送按钮**: 华为蓝背景，包含发送图标

### 响应式设计
- **桌面端**: 三栏布局 (左侧面板 + 主区域 + 右侧面板)
- **平板端**: 两栏布局 (可折叠左侧面板 + 主区域)
- **移动端**: 单栏布局，底部导航

### 动画和交互
- **页面切换**: 淡入淡出动画 (300ms)
- **卡片悬停**: 轻微上升效果 + 阴影加深
- **按钮点击**: 涟漪效果
- **消息发送**: 打字动画效果
- **图表加载**: 渐进式数据加载动画

### 技术实现要点
- 保持Vue 3 + Element Plus技术栈
- 使用CSS Grid和Flexbox实现响应式布局
- 集成ECharts图表库，统一图表主题
- 添加CSS变量系统，支持主题切换
- 使用CSS动画和过渡效果提升交互体验

## 实施优先级

### 第一阶段：核心视觉改进
1. 更新整体配色方案和CSS变量系统
2. 重设计诊断场景卡片
3. 优化消息展示样式
4. 改进工具调用展示

### 第二阶段：布局优化
1. 实现新的顶部导航栏
2. 优化左侧面板设计
3. 添加右侧数据概览面板
4. 实现响应式布局

### 第三阶段：交互增强
1. 添加动画和过渡效果
2. 优化图表展示和交互
3. 实现主题切换功能
4. 性能优化和细节打磨

## 预期效果

- 界面视觉美观度显著提升，更符合专业数据分析工具的定位
- 数据展示更加直观和友好，提升用户的数据分析体验
- 保持原有功能完整性，确保业务流程不受影响
- 提供更好的响应式体验，支持多设备使用
