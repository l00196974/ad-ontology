## 🐛 已修复的问题

### 问题1：OpenAI流式工具调用参数解析错误
**现象**：工具调用参数为undefined或"true"
**原因**：流式响应中工具参数是分块传输的，需要缓冲完整后再解析
**修复**：添加toolCallBuffer缓冲机制

### 问题2：多轮对话时工具定义丢失
**现象**：第二次调用LLM时Tools: 0
**原因**：继续对话时传递了空数组[]而不是skillDefinitions
**修复**：修改server.ts第177行，传递完整的skillDefinitions

### 问题3：dimensions参数传递错误
**现象**：空数组被解析为"true"字符串
**原因**：空数组join(',')后传递给命令行被误解析
**修复**：只在有dimensions时才添加--dimensions参数

### 问题4：配置格式错误
**现象**：使用OpenAI格式调用Anthropic API
**原因**：配置文件格式混淆
**修复**：使用正确的Anthropic配置格式
