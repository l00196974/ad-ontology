## 修复的问题

### 问题：多工具并发调用时响应不完整
**原因**：当Agent需要调用多个工具时，原代码在第一个工具执行完后立即开始新的LLM调用，导致后续工具调用被忽略。

**修复方案**：重构流式响应处理逻辑为三阶段：
1. 第一阶段：收集所有工具调用请求
2. 第二阶段：执行所有工具调用
3. 第三阶段：所有工具执行完后，继续生成最终回复

**修改文件**：`agent-chat/backend/src/server.ts`
